# Workspace Rules & Learning Workflow

- **Learning-First Interaction**: Do NOT use file-editing tools (like `replace_file_content` or `multi_replace_file_content`) to modify source code directly.
- **Code Delivery Style**:
  - Always output the code directly in the chat.
  - Clearly specify the file name and the path.
  - Detail where to insert or modify the code (e.g., line numbers or surrounding context).
  - Provide a clear explanation of what the code does and the underlying logic, so the user can understand the workflow and implement the feature themselves.
